# 知网专业检索语法

> 读完能做什么：把一个中文选题写成知网能跑的检索式，并判断「为什么这条式子命中 0 条」。
> 依据：知网《全球学术快报 2.0 使用手册》1.2.5 专业检索 + 2026-10 两次实检。界面路径与字段以实检为准。

## 1. 字段代码（19 个）

| 代码 | 含义 | 推荐匹配符 | 说明 |
| --- | --- | --- | --- |
| `SU` | 主题 | `%=` | 含专业词典、主题词表、中英对照，召回最宽 |
| `TI` | 题名 | `=` | 中文标题；报纸含引题/副标题 |
| `KY` | 关键词 | `=` | 词表型，精确相等 |
| `AB` | 摘要 | `=` 或 `%` | 中英文摘要 |
| `FT` | 全文 | `%` | 含正文、参考文献，噪声最大 |
| `AU` | 作者 | `=` | 多人用 `+` 连接 |
| `FI` | 第一责任人 | `=` | 第一作者 |
| `RP` | 通讯作者 | `=` | — |
| `AF` | 机构 | `=` | 模糊包含单位名 |
| `JN` | 文献来源 | `=` | 期刊/学位授予单位/报纸名 |
| `RF` | 参考文献 | `%` | 查「谁引用了某文」 |
| `YE` | 年 | 比较符 | `YE BETWEEN ('2016','2026')` |
| `FU` | 基金 | `=` | 基金名称 |
| `CLC` | 中图分类号 | `=` | 学科收窄利器，如 `CLC = D232` |
| `SN` | ISSN | `=` | 期刊唯一标识 |
| `CN` | 统一刊号 | `=` | — |
| `IB` | ISBN | `=` | 图书 |
| `CF` | 被引频次 | 比较符 | `CF > 0`、`CF >= 10` |
| `TKA` | 篇关摘 | `=` | **手册字段表未列，但示例在用**；属版本差异，见 §8 |

## 2. 匹配运算符

| 符号 | 含义 | 适用字段 |
| --- | --- | --- |
| `=` | 精确相等（词表型）；完整包含（文本型） | `KY AU FI RP JN AF FU CLC SN CN IB CF`；`TI AB FT RF` |
| `%` | 模糊：检索词分词后包含 | `TI AB FT RF`；`KY AU FI RP JN FU` |
| `%=` | 相关匹配（带主题词表扩展） | **仅 `SU`**；`CLC SN CN IB` 为完整包含 |

要点：`SU` 只用 `%=`，写 `SU =` 会报语法错或命中异常；`TI` 用 `=` 是「完整包含该串」，不是「整标题等于」。

## 3. 逻辑运算符

```text
AND  与      OR  或      NOT  非
```

- 前后必须留**半角空格**：`KY = 知识管理 AND AU = 邱均平`
- 优先级用**英文半角圆括号**：`AU = 钱伟长 AND (AF = 清华大学 OR AF = 上海大学)`
- 可自由嵌套，但建议不超过 3 层；超过就拆成 `#1 #2` 多步（知网界面不支持历史集，需人工合并）

## 4. 字段内复合运算

```text
*  与      +  或      -  非
```

```text
TI = (文化大革命 + 无产阶级文化大革命) * (理论 + 无产阶级专政 + 阶级斗争)
KY = 铝合金 + 钛合金
KY = 大数据 - 人工智能
```

- 每条复合表达式**只作用于一个字段**
- 运算符前后留空格
- 整个检索框 ≤ **120 字符**（含括号与空格），超了必须拆行

## 5. 位置描述符（单字段内，只限两个值）

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| `#` | 同句出现 | `FT = '人工智能 # 推荐算法'` |
| `%` | 同句且前者在前 | `FT = '人工智能 % 推荐算法'` |
| `/NEAR N` | 同句、间隔 ≤N 字词 | `FT = '人工智能 /NEAR 10 推荐算法'` |
| `/PREV N` | 同句、前者在前且间隔 ≤N | `FT = '人工智能 /PREV 10 推荐算法'` |
| `/AFT N` | 同句、前者在后且间隔 ≤N | `FT = '人工智能 /AFT 10 推荐算法'` |
| `/SEN N` | 同段、句序号差 ≤N | `FT = '人工智能 /SEN 1 推荐算法'` |
| `/PRG N` | 间隔 ≤N 段 | `FT = '出版 /PRG 5 法规'` |
| `$ N` | 关键词至少出现 N 次 | `FT = '大数据 $5'` |

**硬约束**：检索值与运算符必须整体用**英文半角单引号**括起；这些描述符**只能连接两个值**，不能串三个。

## 6. 比较运算符

```text
YE BETWEEN ('2010', '2018')     出版年区间
CF > 0                          被引频次大于 0
CF >= 10                        被引 ≥10
```

## 7. 界面（高级检索）约束

| 约束 | 值 | 影响 |
| --- | --- | --- |
| 检索项行数 | ≤ 10 行 | 超过要拆多次检索 |
| 行间运算顺序 | **从上到下依次** | 不是全局 AND，括号只作用于行内 |
| 单框字符 | ≤ 120 | 长式子必拆 |
| 默认中英文扩展 | 开启 | 中文词会同时检英文，召回变大；要精确就手动取消 |
| 「结果中检索」 | 与前条件 AND | 等价于追加一个 AND，但会改写检索历史 |
| URL 传检索式 | **无效** | 结果内嵌渲染，`defaultresult/index?kw=` 只支持单关键词；`SU=(...)` 传 URL 返回 0 条 |

## 8. 版本差异（实检记录）

| 现象 | 手册 | 实检 | 处置 |
| --- | --- | --- | --- |
| 关键词字段 | `KY` | `KW` 也能用，且更窄 | `KY` 返 0 而 `KW` 有结果时用 `KW`，台账 `note` 记「版本差异」 |
| 篇关摘 | 未列 | 示例里出现 `TKA` | 需要「篇名或摘要」时优先 `TI` OR `AB`，不要依赖 `TKA` |
| 检索项命名 | 「主题/篇关摘/…」 | UI 文案可能随版本变 | 填之前先 `observe` 看清当前文案，别按记忆点 |

## 9. 五个可复制范式

```text
# 1 宽式探路（先看这个题目有多少量）
SU %= 基层治理

# 2 篇名精式（噪声最小，适合定核心文献）
TI = (基层治理 + 基层社会治理) * (数字化 + 数字技术 + 技术治理)

# 3 主题+学科双限（压掉跨学科噪声）
SU %= (基层治理 * 数字化) AND CLC = D63

# 4 作者+机构（追一个团队的全部产出）
AU = 某某某 AND AF = 某某大学

# 5 基金+年段（找项目结项成果）
FU = 国家社会科学基金 AND YE BETWEEN ('2019','2026')
```

## 10. 语法自检（写完逐条打勾）

- [ ] 括号成对，且都是英文半角 `(` `)`
- [ ] `AND/OR/NOT` 前后有空格；`* + -` 前后有空格
- [ ] `SU` 用的是 `%=`，不是 `=`
- [ ] 单框 ≤120 字符（`python3 -c "print(len('...'))"` 量一下）
- [ ] 没有全角 `（` `）` `＊` `＋` `－`
- [ ] 字段代码在 §1 表内
- [ ] 检索值里的特殊符号（`+ - * ( ) / % =`）已用半角单引号包住
- [ ] 编号词/泛动词已配领域词共现（见 `method/query-design.md` §6）
