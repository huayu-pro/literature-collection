# 检索式构造方法论

> 读完能做什么：给定一个题目，产出 3–9 条有梯度的检索式，并知道每条命中太多/太少时改哪一个变量。
> 适用：知网与 WOS 通用；平台语法分别见 `cnki/cnki-syntax.md` 与 `wos/wos-playbook.md`。

## 1. 四类语义关系（以「资深学者」视角发散）

| 类型 | 定义 | 中文例 | 英文例 |
| --- | --- | --- | --- |
| 同义 | 所指完全相同 | 文化大革命 / 文革 | Donald Trump / Trump |
| 近义 | 所指高度重叠但不等同 | 民营经济 / 非公有制经济 | populism / populist politics |
| 上下位 | 概念包含关系 | 干部人事制度 ⊃ 党管干部 | political communication ⊃ media discourse |
| 相关 | 常共现的理论/机制/场景 | 政治传播 / 框架理论 / 议程设置 | framing / agenda setting / priming |

规则：
- 同义、近义进 **OR 组**；上下位**慎用**——下位词单独成组，不要直接塞进同义组（会把召回放大一个量级）。
- 「相关」词只放在**第二个 AND 块**，不要和主题词平铺。
- 一个 OR 组 **2–5 个词**；超过 5 个拆成两组，用两个检索式分别跑。

## 2. 扩展流程（15 分钟）

1. **种子词**：从用户题面提取 2–4 个核心词，先只跑一条宽式探路。
2. **四类发散**：每类至少写 3 个，合计 ≥12 个；写不出来就说明你对这个领域不熟，先读 2 篇综述再回来。
3. **去歧义**：删掉裸词（见 §6），删掉跨学科高频但无关的词。
4. **按字段分组**：核心概念进 `TI/TS`，方法/理论词进 `SU/AB`，学科词进 `CLC/WC`。
5. **成型**：`(核心词OR组) * (限定词OR组)`，再按平台语法改写。
6. **试检**：先跑最窄的一条，看命中量落在哪个区间（§5）。

## 3. 中英对照样例（四组领域）

| 领域 | 中文 OR 组 | 英文 OR 组 |
| --- | --- | --- |
| 政治学 | 民粹主义 / 民粹 / 平民主义 | populism / populist / nativism |
| 传播学 | 政治传播 / 政治沟通 / 媒介话语 | political communication / media discourse / political rhetoric |
| 党史 | 继续革命 / 无产阶级专政下继续革命 / 文革 | continuous revolution / cultural revolution |
| 经济史 | 民营经济 / 非公有制经济 / 私营经济 | private economy / non-state economy / private enterprise |

## 4. 字段选择：精度—召回阶梯

| 平台 | 从窄到宽 | 用法 |
| --- | --- | --- |
| 知网 | `TI` → `KY` → `SU` → `AB` → `FT` | 先用 `TI` 跑 20 条看噪声，再退一级 |
| WOS | `TI` → `TS` → `AB` → `AK` | `TS` 已覆盖标题+摘要+关键词+Keywords Plus，通常直接用 `TS` |

经验值：
- `TI` 命中 <10 条 → 说明题目太新或词太窄，退到 `SU/TS`。
- `FT` 命中 >5000 条 → 说明检索词太泛，回 `TI` 或加学科限定。

## 5. 命中量收敛

| 命中量 | 判断 | 只改一个变量（按优先级） |
| --- | --- | --- |
| < 50 | 太窄 | ① 去掉一个 AND 块 ② 换上位词 ③ 去年份限制 ④ 字段退一级 |
| 50–3000 | 目标区 | 不动式子，进入质量筛选 |
| > 5000 | 太宽 | ① 字段进一级（`SU`→`TI`）② 加一个 AND 领域词 ③ 加 `CLC/WC` 学科限定 ④ 缩年段 |

**铁律：每次只改一个变量，改完立刻记账。** 一次改三个，命中量变了你也不知道是谁的功劳。

## 6. 歧义词与噪声词规则

| 类型 | 例子 | 处置 |
| --- | --- | --- |
| 编号词 | 十六条、五一六通知、二十三条 | 必须与领域词共现：`TI = 十六条 * (文革 + 社会主义教育运动)` |
| 泛动词 | 夺权、批判、改革、治理 | 不单独使用；必须 `* 领域名词` |
| 裸词黑名单 | 文革、改革、治理、数字化 | 单独出现时一律不加引号裸跑 |
| 同名异指 | 「物理」既指学科也指「物理空间」 | 加 `CLC` 或 `SU` 限定 |
| 英文缩写 | AI、US、PR | 加引号并配全称：`"artificial intelligence" OR AI` |

实测案例：「十六条」裸跑命中《合同法》第 286 条相关文献；加 `* (文革 + 社会主义教育运动)` 后噪声归零。

## 7. 六个可复制模板

```text
# 知网 1 宽式（先探量）
SU %= {核心词}

# 知网 2 精式（核心文献）
TI = ({核心词} + {同义词}) * ({限定词} + {近义词})

# 知网 3 作者/机构（追团队）
AU = {姓名} AND AF = {机构}

# WOS 1 主式（TS 一次覆盖）
TS=({core} OR {synonym}) AND TS=({qualifier} OR {related})

# WOS 2 分步组合（复杂逻辑用历史集）
#1 TS=({core} OR {synonym})
#2 TS=({qualifier}) AND WC=("{category}")
#1 AND #2

# WOS 3 期刊+年段（追特定期刊）
SO="{journal}" AND TS=({core}) AND PY=(2016-2026)
```

## 8. 检索台账（每条式子一行）

| 列 | 含义 | 示例 |
| --- | --- | --- |
| `qid` | 检索序号 | `Q03` |
| `platform` | `cnki` / `wos` | `cnki` |
| `query_raw` | 原样检索式 | `TI = (基层治理 + 基层社会治理) * 数字化` |
| `fields` | 用到的字段 | `TI` |
| `refine_before` | 筛选前命中数 | `412` |
| `refine_after` | 筛选后条数 | `38` |
| `hits` | 采用条数 | `30` |
| `date` | 检索日期 | `2026-10-24` |
| `institution` | 机构/登录方式 | `XX大学（机构IP）` |
| `note` | 版本差异/异常 | `KY 返 0，改用 KW` |

台账是报告的可复现凭据：**没有台账的检索等于没做**。
